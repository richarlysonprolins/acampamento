# 🏕️ Sistema Desbravadores

Sistema de gerenciamento e pontuação para clubes de desbravadores.

## ✨ Funcionalidades

- ✅ Gerenciamento de Unidades
- ✅ Controle de Membros
- ✅ Sistema de Pontuação
- ✅ Ranking em Tempo Real
- ✅ Brincadeiras Personalizadas
- ✅ Painel Administrativo

## 🚀 Tecnologias

- **Frontend**: Vue.js 3 + Vuetify 3
- **Backend**: PHP + MySQL
- **Hospedagem**: Netlify (Frontend) + 000webhost (Backend)

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Desenvolvimento
npm run dev

# Build produção
npm run build
```
